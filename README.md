# Hive Painel

Painel administrativo para gerenciar vendas de acesso a grupos do Telegram via bots PIX.

## Funcionalidades

- Gerenciamento de bots e grupos Telegram
- Conexão com gateways de pagamento (SigiloPay, Mercado Pago, etc.)
- Geração de cobranças PIX
- Postagens automáticas em grupos
- Remarketing e campanhas
- Gerenciamento de afiliados
- Dashboard com métricas em tempo real
- Suporte a múltiplos gateways (24+)

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- Express (server-side)
- Chart.js

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

O deploy é automático via GitHub push para Railway.
